# New World

A turn-based game of founding colonies in the New World and leading them to independence. You sail from Europe, explore the coast, found colonies and put their people to work, trade with Europe and the native peoples, and in time declare independence and fight the Crown for it. It is free and runs in the browser.

Play it at <https://colebrumley.github.io/new-world/>.

For the user guide, see the [wiki](https://github.com/colebrumley/new-world/wiki).
